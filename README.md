# E-commers-sales-Analytics
An interactive E-commerce sales dashboard to analyze sales, profit, orders and product performance using Power BI.

# E-Commerce Sales Analytics Dashboard

# Project Overview

This project presents an interactive E-Commerce Sales Analytics Dashboard built using Microsoft Power BI. It helps analyze sales performance, profit, orders, product performance, and customer purchasing patterns.

# Tools & Technologies

- Microsoft Power BI
- Microsoft Excel

# Dashboard KPIs

- Total Sales: 78M
- Total Orders: 1K
- Total Profit: 7.21M
- Total Quantity: 3K
- Average Order Value: 77.84K

# Key Features

- Sales Analysis by Category
- Monthly Sales Trend
- Profit Analysis by Category
- Top 10 Products by Sales
- Sales Analysis by Payment Mode
- City-Wise Sales Analysis
- Interactive Filters for Order Date, Category, City, and Payment Mode

# Business Insights

- Compare sales performance across different product categories.
- Track monthly sales trends and identify changes in performance.
- Identify the most profitable product categories.
- Analyze the top-performing products based on sales.
- Understand customer payment preferences.
- Compare sales performance across different cities.

# Project Objective

The objective of this project is to transform sales data into meaningful visual insights that help businesses monitor performance and make data-driven decisions.

# Conclusion

This dashboard provides a clear overview of e-commerce sales performance through interactive visualizations, KPIs, and category-wise analysis.
